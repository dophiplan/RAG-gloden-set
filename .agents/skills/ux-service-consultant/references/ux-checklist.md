# UX 체크리스트 템플릿

## 1. 기본 UX 체크리스트

### 1.1 피드백 (Feedback)
- [ ] 사용자 액션 후 즉각적인 피드백이 있는가?
- [ ] 로딩 상태가 표시되는가? (스피너/프로그레스)
- [ ] 성공/실패 알림이 표시되는가?
- [ ] 에러 메시지가 사용자 친화적인가?

### 1.2 일관성 (Consistency)
- [ ] 같은 동작은 같은 방식으로 작동하는가?
- [ ] UI 요소(버튼, 색상, 폰트)가 일관된가?
- [ ] 용어가 일관되게 사용되는가?
- [ ] 레이아웃이 페이지 간 일관된가?

### 1.3 효율성 (Efficiency)
- [ ] 자주 사용하는 기능에 단축키가 있는가?
- [ ] 반복 작업을 줄일 수 있는 기능이 있는가? (벌크 작업)
- [ ] 이전 입력을 기억하는가? (자동완성)
- [ ] 페이지 로딩이 빠른가?

### 1.4 오류 방지 (Error Prevention)
- [ ] 위험한 액션에 확인 대화상자가 있는가? (삭제 등)
- [ ] 입력 유효성 검사가 즉시 이루어지는가?
- [ ] 되돌리기(Undo) 기능이 있는가?
- [ ] 자동 저장 기능이 있는가?

---

## 2. 번역 관리 시스템 특화 체크리스트

### 2.1 번역 작업 플로우
- [ ] 새 번역 추가가 쉬운가? (3클릭 이내)
- [ ] 원문과 번역문을 동시에 볼 수 있는가?
- [ ] 컨텍스트(맥락) 정보가 쉽게 보이는가?
- [ ] 이전 번역 히스토리를 참조할 수 있는가?
- [ ] 용어집과 연동되어 자동 추천되는가?

### 2.2 협업 기능
- [ ] 작업 할당이 가능한가?
- [ ] 작업 상태가 실시간으로 공유되는가?
- [ ] 댓글/노트로 소통할 수 있는가?
- [ ] 변경사항 알림이 가는가?
- [ ] 승인/검수 워크플로우가 있는가?

### 2.3 파일 관리
- [ ] PDF에서 텍스트 추출이 정확한가?
- [ ] 다중 파일 업로드가 가능한가?
- [ ] 버전 관리가 되는가?
- [ ] Excel Import/Export가 가능한가?
- [ ] 파일 미리보기가 있는가?

### 2.4 검색/필터
- [ ] 전문 검색(Full-text)이 가능한가?
- [ ] 고급 필터(날짜, 상태, 담당자 등)가 있는가?
- [ ] 필터 조합을 저장할 수 있는가?
- [ ] 검색 결과가 하이라이트되는가?
- [ ] 최근 검색어가 저장되는가?

---

## 3. 모바일/반응형 체크리스트

- [ ] 모바일에서 테이블이 스크롤 가능한가?
- [ ] 터치 타겟이 44px 이상인가?
- [ ] 모바일에서 주요 기능이 작동하는가?
- [ ] 가로/세로 전환 시 레이아웃이 깨지지 않는가?
- [ ] 확대/축소가 자유로운가?

---

## 4. 접근성 체크리스트

- [ ] 키보드만으로 모든 기능 사용 가능한가?
- [ ] 스크린 리더가 내용을 읽어주는가?
- [ ] 색상 대비가 충분한가? (4.5:1 이상)
- [ ] 포커스 표시가 명확한가?
- [ ] 이미지에 alt 텍스트가 있는가?

---

## 5. 성능 체크리스트

- [ ] 페이지 로딩이 3초 이내인가?
- [ ] 테이블에 가상 스크롤이 적용되어 있는가?
- [ ] 이미지가 최적화되어 있는가?
- [ ] API 호출이 중복되지 않는가?
- [ ] 메모리 누수가 없는가?

---

## 6. 보안 체크리스트

- [ ] 민감한 데이터가 노출되지 않는가?
- [ ] 권한 없는 접근이 차단되는가?
- [ ] XSS 방어가 되어 있는가?
- [ ] CSRF 토큰이 적용되어 있는가?
- [ ] 입력값이 검증되는가?
