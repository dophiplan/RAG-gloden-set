## 🔄 최종 프로세스 (3단계)

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        마이그레이션 3단계 프로세스                         │
└─────────────────────────────────────────────────────────────────────────┘

  ●────────●────────●
  1        2        3
 파일      필드      미리보기/반영
 업로드    매핑
```

**단계별 설명**:
1. **파일 업로드**: 파일 선택 + 제품 선택
2. **필드 매핑**: 파일 컬럼 ↔ 시스템 필드 매핑
3. **미리보기/반영**: 
   - 매핑 결과 미리보기
   - 체크박스로 행 선택
   - 용어집/번역관리/제외/삭제 분류
   - 일괄 작업
   - 반영(Commit) 및 결과 확인

### Step 3: 미리보기/반영 (통합)

**기능**:
- 매핑 결과 테이블 미리보기
- **체크박스**로 여러 행 선택 (전체 선택 가능)
- 행별 액션: 번역관리/용어집/제외/삭제
- **일괄 작업 바**: 선택된 행에 일괄 적용
- 중복/유사 표시
- 최종 반영(Commit)
- 결과 요약

**액션 타입**:
| 액션 | 설명 | 기본값 |
|------|------|--------|
| ✓ 번역관리 | 번역관리에 저장 | ✅ 기본 |
| 📖 용어집 | 용어집에 저장 | 선택 시 |
| ⏭️ 제외 | 저장하지 않음 | 선택 시 |
| 🗑️ 삭제 | 완전히 제외 | 선택 시 |

**일괄 처리 플로우**:
```
1. 체크박스로 여러 행 선택 (전체 선택 가능)
2. 하단 "일괄 작업" 바에서 액션 선택
3. "적용" 클릭 → 선택된 모든 행에 액션 적용
4. 최종 "반영" 버튼으로 DB에 저장
```

## 🏗️ 구현 계획 (사이드 이펙트 ZERO)

### 접근 방식: "새로 만들기" 전략

**기존 파일 건드리지 않음**:
- `/src/app/(dashboard)/settings/migration/page.tsx` → **백업** 후 새로 작성
- `/src/app/api/migration/*` → **백업** 후 새로 작성
- 기존 컴포넌트는 **그대로 유지** (fallback용)

**새 파일 구조**:
```
src/app/(dashboard)/settings/migration/
├── page.tsx                    # 새로 작성 (기존은 page.tsx.backup)
├── layout.tsx                  # MigrationProvider 추가
├── _backup/                    # 기존 파일 백업
│   ├── page.tsx.backup
│   └── components.backup/
├── components/
│   ├── MigrationWizard.tsx     # 새로 작성 (3단계)
│   ├── StepIndicator.tsx       # 새로 작성 (3단계 네비게이션)
│   ├── steps/
│   │   ├── UploadStep.tsx      # 새로 작성
│   │   ├── MappingStep.tsx     # 새로 작성 (버전 없음)

│   └── shared/

├── contexts/
│   └── MigrationContext.tsx    # 새로 작성
└── hooks/
    └── useMigration.ts         # 새로 작성
```
