### Preview API 요청
```
┌────────────────────────────────────────────────────────────────┐
│  POST /api/migration/preview                                   │
├────────────────────────────────────────────────────────────────┤

│  {                                                             │
│    file: File,                                                 │
│    product_code: "rmsolution",                                 │
```

## 5. 컴포넌트 구조

```
FieldMapping.tsx
├── 왼쪽 패널
│   ├── 버전 선택 (SheetSelector)
│   │   └── 시트 이름 목록
│   │       ├── RMAndroid (선택됨)
│   │       ├── RMStandard
│   │       └── sass_sfu
│   │
│   └── 파일 컬럼 (ColumnList)
│       └── 드래그 가능한 컬럼 목록
│
└── 오른쪽 패널
    └── 시스템 필드 (SystemFields)
        ├── 원문 (DropZone)
        ├── 번역 (MultiDropZone)
        ├── KEY/ID (DropZone)
        ├── 제품분류 (SmartDropZone) ◀── 수정 대상
        │   ├── 값 표시: "RMAndroid"
        │   ├── 소스 표시: "📄 시트 이름"
        │   └── 토글 버튼: [직접입력] [컬럼]
        ├── 버전 (DropZone)
        └── 문맥 (DropZone)
```

## 6. Phase별 UI 변화

### Phase 0: 현재 (문제)
```
제품분류*  [여기로 드래그]
          (비어있음)
```

### Phase 1: 자동 매핑
```
제품분류*  [여기로 드래그]
          ← RMAndroid
```

### Phase 2: 소스 표시
```
제품분류*  [여기로 드래그]
          ← RMAndroid
            📄 시트 이름에서 자동 설정
            [직접 입력으로 변경]
```

### Phase 3: 직접 입력
```
제품분류*  [여기로 드래그]
          ┌─────────────┐
          │ RMAndroid   │
          └─────────────┘
            ✏️ 직접 입력 모드
            [📄 시트명으로] [⬅️ 컬럼으로]
```
