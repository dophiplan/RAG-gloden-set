새 제품 평가 시작하기
이건 순서 선택이 아니에요 — 어디서 시작할지는 올리는 파일이 정해요:
· 문서 뭉치(코퍼스)만 → 처음부터 시험지 제작
· 골든셋(시험지)이 이미 있음 → 해당 단계 폴더에 넣으면 건너뜀
· 응답 로그까지 있음 → 채점만 진행
추가하면: 폴더 만들어지고 → "파일 올려주세요" 카드가 떠요 (📎 업로드 버튼)
