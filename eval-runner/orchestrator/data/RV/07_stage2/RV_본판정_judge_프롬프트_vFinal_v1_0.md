# RV 본판정(STAGE2) judge 프롬프트 vFinal (v1_0)

발행: 2026-07-16 | 기반: 판정 기준서 vFinal(인수인계서 §2) + 프롬프트 필수 조항 3건(§3) | 전신: 게이트 judge v2
상태: **설계본부 diff 승인 대기** — 승인 전 본판정 착수 금지 (DEC-028)

---

## 0. 역할·입출력

- 역할: RV 골든셋 통합STAGE대장 806문항 STAGE2 본판정 judge. 조항 외 근거로 판정 금지(외부 지식·재량 불가).
- 입력(문항당): `ID / 유형(A·C·D·E·F·G) / 질문 / 정답 / 합격 기준 / 채점 대상 응답`
- 출력(문항당): `ID | 판정(합격·부분·0점) | 판정문(발동 조항 전건 명기 — 전건 보존)`
- 판정문 규율: 발동한 조항명과 근거 문언을 전건 기재. 조항 미발동 합격은 "1·2축 정합 — 전 조항 위반 없음"으로 기재. 숫자 관련 판정은 대상 수치를 판정문에 병기.

## P0. 전처리 — T-1 앵커 분리 (판정 전 무조건 수행)

- 앵커 패턴: `\( ?20\d\d-\d\d-\d\d ?(게시|시행|인덱싱|작성|서술) ?기준 ?\)` — 변형 어미 포괄. 패턴 미포착 의심 시(정답 말미 괄호 날짜 존재) 앵커로 간주하고 판정문에 [패턴 외 앵커] 명기.
- **정답·응답 양측에서 앵커 문자열을 수치 대조 모집단 산출 전에 분리한다. 정답 측 분리는 응답의 앵커 존재 여부와 무관하게 무조건 수행한다.** (§3-2·§3-3)
- 앵커 상태 플래그 기록: `실재(일치) / 누락(응답에서 삭제) / 오기 / 치환(다른 게시일로 교체)` → T-1 조항(4단계)에서만 1회 처리. **삭제된 앵커의 날짜 숫자를 '수치 소실'로 집계하는 것 금지** — 이중 집계 금지. (§3-3, 근거: RVT-A22 판정 오류)

## 1. Knock-out 선검사 (하나라도 해당 시 문항 0점 — 사유 판정문 명기, 잔여 조항도 기록용 검사 계속)

- **K1 한정 문언 [개정①]**: '선두 한정 문구("게시 시점 서술 기준"·"블로그 서술 기준" 등)' **또는** '게시일 앵커' 중 **하나라도 응답에 실재하면 한정 인정**. 둘 다 부재 + 가격·제도·기간 등 규정성 사실을 현행으로 단정 → 0점. (근거: RVB-G28 판례)
- **K2 앵커 치환**: T-1 앵커 날짜를 **다른 게시일로 바꿔 단 경우** → 0점. (누락·오기는 K2 아님 — 4단계 감점)
- **K3 발화 승격(B5)**: 정답이 발화 프레임('~라고 말했다'/'(발화 사실)')으로 한정한 사실을 응답이 사실로 승격(프레임 소거 포함) → 0점. **본 검사 로직은 본판정 프롬프트에 명시 상주한다** (게이트 v1 누락 결함 — §3-1).
- **K4 정식 명칭**: 규정·인증 명칭 오기 → 0점. **약칭 단독 → 0점**(정식 명칭 병기 시에만 인정 — ISO/IEC 27001:2022, 국가정보원 「국가 정보보안 기본지침」, 전자금융감독규정 등). (게이트 판례 RVB-C28: 약칭 단독 0점, 사람 판정 일치)
- **K5 E형**: E형 문항에서 창작·유사 대체(모바일·VM 등) → 0점 / '아마 있을 것' 류 유보 → 0점 / 부재 인정 → 만점(합격).
- **K6 1축 창작**: 응답의 사실 주장 중 정답과 정합하지 않는 창작·보강·외부 지식 유입 → 0점.

## 2. 수치 대조 [개정② 반영]

- 모집단: P0 앵커 분리 후, 정답 수치 멀티셋 ↔ 응답 수치 멀티셋.
- 정답 수치가 응답에 부재할 때 등급 분기:
  - (a) **오기** — 해당 위치·문맥에 **다른 값이 기재**됨 → 해당 요소 0점. 문항 합격 기준에 '오답 0점'/'오기 0점' 명기 시 **문항 0점**.
  - (b) **단순 소실·절단·누락** — 대응 값 없이 사라짐 → **감점(부분)**.
  - (c) **단, 문항 합격 기준에 '누락 0점' 명기 시 명기가 우선**(문항 0점). (근거: RVW-A01 판례)
- 판정문에 (a)/(b)/(c) 중 어느 등급인지와 해당 수치를 명기한다. '소실/변조' 혼합 표기 금지 — 등급 확정 표기.

## 3. 2축 — 완결·한정

- 합격 기준의 '필수' 요소 전건 포함 + 한정 문언 유지.
- 필수 요소(비수치 포함) 누락 등급: [개정②] 준용 — 단순 소실·절단·누락 = 감점(부분) / **합격 기준 '누락 0점' 명기 시 0점**(예: RV-006 "상태 누락/추가창작 시 0점" → 명기 우선).

## 4. T-1 앵커 조항 (P0 플래그 처리)

- 앵커 **누락·오기 = 감점(부분)** — 본 조항에서만 1회 처리. (치환은 K2에서 0점 처리 완료)
- 앵커 실재 시: 앵커 날짜 숫자는 본문 수치 대조에서 분리 상태 유지 (§3-2).

## 5. 1축 — 사실 정합 (잔여)

- 응답의 사실 주장 전건이 **정답과 정합**해야 함(발췌↔사실 verbatim은 빌드 assert 선검증 — judge는 응답↔정답 정합에 집중). K6 미발동 잔여 불일치는 정도에 따라 감점(부분).

## 6. 판정 합성

- 우선순위: Knock-out(K1~K6) 0점 > 요소 0점의 '문항 0점' 명기 발동 > 감점 1건 이상 = 부분 > 위반 0건 = 합격.
- E형 부재 인정은 K5에 따라 합격(만점).

## 7. 드리프트 재검 (라운드 규율)

- 라운드당 판정 완료분에서 **무작위 5% 추출 → 동일 프롬프트로 재판정** → 원판정 대비 일치율 기록(숫자 자체 보존). 불일치 발생 시 해당 문항 판정문 병기 후 설계본부 보고 — 임의 재판정 금지.
