r1 시험지(834+199)는 접는다. r2는 관제판 파이프라인(앙상블: 출제 claude · 채점 kimi · 교차 codex)으로
**처음부터 새로 출제**한다. 단독 세션이 만들던 신규 문항 35건은 중단·보관(채점센터 vault
`09_r2_시험지/CI_r2_원장.jsonl`) — 파이프라인 검수큐에 후보로 넣을지는 나중에 결정.

## 재시작 방법 (Mac 터미널)

```bash
cd ~/eval-runner/orchestrator
python3 tools/pipeline.py onboard --product CI --force --start full --strategy ensemble
python3 tools/pipeline.py run --product CI
```

이후 검수큐/대시보드에서 단계 게이트 승인하며 진행 (기존 RV2·RC2와 동일한 흐름).

## r1에서 배운 것 — 이번 출제에 반영할 규칙 (채점센터 요청)

1. **발췌는 코퍼스 원문에서 그대로 복사, 20자 이상** — r1 결함: 발췌 20자 미만 130건이
   우연 일치로 점수를 부풀림 + 골든셋-코퍼스 수치 불일치 4건(사람이 옮겨적다 생긴 오타).
2. **유형 라벨 고정 어휘**: 사실확인/수치/절차/조건/가부/정의 (+E형) — r1은 라벨 177종 난립.
3. **정답 필수요소에 수치·고유명사 명시** (판정기준서 v1.1 엄격 항목과 정합).
4. 발췌의 청크 내 오프셋 기록 권장 — 리랭커 절단 영향의 회차 측정용.

## 채점센터(vault)가 발행 직전에 병합하는 것 — 파이프라인 출제 범위 아님

- **앵커 120문항** (r1 문항 층화 재사용, 어느 것인지 비공개) — 회차 간 비교선 유지
- **E형(자료 부재) 40문항** (부재 기계검증 완료본 재사용)
- 최종 발행본 = 파이프라인 신규분 + 앵커 120 + E형 40, 고정 시드 셔플
