## 개정 내용 — 출제 쿼터 (v3 대표 추출·차수 생성에 반영)

| 유형 | 쿼터 | 출제 방법 |
|---|---|---|
| **E형 함정** | 전체의 **10%** | 코퍼스에 부재함을 확인한 주제(요금·타사 비교·미출시 기능 등)로 출제. 정답 = "자료에 없음을 밝히고 답변 보류" (v1 방식 복원) |
| **복합 질문** | **10%** | 두 개 이상 단위/문서를 결합해야 답이 되는 문항 (비교·조건 분기·목록 종합). 근거 출처에 복수 단위 병기 |
| **표 기반** | **5%** (표 청크 보유량 내) | 표 청크(파이프≥6)에서 셀 값·행 비교를 묻는 문항. 발췌는 표 원문 연속 문자열 |
| **그래프 기반** | 조건부 | 이미지 처리분 export 수령 시에만 편성 — 미수령이면 "측정 불가"로 리포트에 명기 |

## 구현 지점

- `config.yaml` → `pipeline.goldenset_quota` (예약 완료 — v3 착수 시 활성화)
- `gen_goldenset.py`: ① select_representative에 표 청크 우선 슬롯 ② 차수 생성 payload에 유형 쿼터 지시 ③ E형 생성 규칙(v1 생성규칙서 §E 복원) ④ 검수 8종에 쿼터 충족 검사 추가
- 채점: E형·복합은 생성축 채점 필요 → 해당 회차는 전체 응시(answer 포함) 필수 명기

## 수용 기준 (검수 게이트)

1. v3 마감 카드에 유형별 쿼터 충족 실측 표기 (E형 ≥10% · 복합 ≥10% · 표 ≥5% 또는 보유량 사유)
2. E형 문항의 부재 근거: 코퍼스 전수 검색으로 "정말 없음"을 스크립트 확인 (환각 함정의 오염 방지)
3. 복합 문항의 근거 출처는 복수 단위 — 검수 ③(citation 실재)이 전 단위 검증
4. 본부장님 질의 3종(표·그래프·복합)에 대한 측정 결과가 회차 리포트 표준 섹션에 포함
