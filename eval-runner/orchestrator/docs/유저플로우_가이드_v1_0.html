  2. 코퍼스 보강(매뉴얼·FAQ 등) — 오른쪽 위 청록색 ＋ 코퍼스 보강 (증분 확대) → 추가분만 올리면 기존 문항·성적은 그대로 두고 새 재료만 출제해 골든셋이 커집니다.
