### 확인된 API 특징

- **프로토콜**: HTTP/1.1
- **데이터 형식**: JSON (`Content-Type: application/json`, `Accept: application/json`)
- **인증 방식**: Bearer 토큰 기반 인증 (`Authorization: Bearer SecretKey`)
- **주요 엔드포인트 예시**:
  - `POST /wv/sdk/secret/verify` — SDK 사용자 인증
  - `GET /wv/sdk/start` — WebViewer SDK 실행
- **접속 정보**: `https://remotecall.io`

## 📌 리모트콜 약관 내 분할 납부(할부) 규정 여부

리모트콜 이용약관에는 **회원 간 서비스 이용료를 분할 납부(할부)할 수 있다는 규정은 없습니다**.

### 확인된 약관 내용
- **정회원의 납입 의무**
  약관은 정회원을 ‘유료서비스 이용계약의 당사자로서 이용요금의 납입의무를 가진 법인이나 개인’으로 정의하고 있습니다.[citation:1]

- **요금 납부(결제) 방법(제25조)**
  이용요금은 무통장입금, 은행자동이첸납부, 신용카드결제 등 회사가 제공하는 결제방식으로 납부하며, 서비스별로 결제수단이 일부 제한될 수 있습니다.[citation:2]

- **요금의 청구 및 납부(제26조)**
  정회원은 서비스 개통 전에 이용요금을 **선납(결제)**하여야 하고, 무통장입금 방식일 경우 신청 완료 후 **1주일 이내**에 해당 금액을 입금해야 합니다.[citation:2]

약관상 이용요금은 정회원이 선납 의무를 지며, 회원 간 분할 납부나 할부에 대한 특별 규정은 **마련되어 있지 않습니다**. 실제 분할 납부 필요 시에는 리모트콜 고객센터 또는 영업 담당자와 **별도 협의**가 필요합니다.

### 1. 인터넷 연결이 필수 사용 환경

리모트콜의 공식 사용 환경 안내 문서에서는 상담원과 고객 모두 **“네트워크 및 인터넷 사용 가능 환경”**이 필수라고 명시하고 있습니다.

- 상담원은 에이전트와 뷰어를 이용하여 **인터넷을 통해** 고객 지원을 합니다.
- 고객은 **인터넷이 가능한 순수한 웹 브라우저 환경**에서 지원을 받을 수 있습니다.
- 방화벽 설정 역시 Out Bound 80(http) / 443(https) Port Open을 권장합니다.

### 2. 원격지원 접속 과정 자체가 인터넷 기반

원격지원이 이루어지는 전 과정이 인터넷 연결을 필요로 합니다.

- 고객은 [113366.com](https://www.113366.com)에 접속하여 접속번호를 입력합니다.
- 페이지 접속 후 자동으로 모듈 업데이트가 실행되며, 업데이트 서버와 통신합니다.
- 원격연결을 위해 릴‑레이 서버에 접속하고, 연결이 원활하지 않을 경우 추가 릴‑레이 서버에 자동 접속을 시도합니다.

### 3. “오프라인”이라는 표현은 영상지원(비주얼팩)에만 사용됨

리모트콜 웹사이트에서 “오프라인”이라는 단어는 **스마트폰 칩로 현장을 촬영하는 영상 기반 원격지원(비주얼팩)**의 맥락에서만 등장합니다. 예를 들어 “오프라인 현장을 스마트폰 치메라로 촬영해 실시간으로 공유”한다는 의미이며, 이 역시 실시간 영상
