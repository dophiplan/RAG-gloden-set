## 4. 응시 방법 (`08_scoring/tools/vertex_run.py`)

- 시험지: `CI_질문셋_발행본_v2_0.xlsx` 488문항(문항ID·질문) — **정답 미사용**
- 문항마다 2회 호출: (a) 검색만 `page_size=5` → hits · (b) 검색+답변 생성 → answer. **동시성 1(순차)**
- 지연 정의: **클라이언트(서울, 난희 Mac) → Vertex global 엔드포인트 API 왕복 벽시계 ms.** 팀장님 수치(서버 내부 처리 시간)와 **단위가 다름** — 비교 시 명시
- 출력 형식: 팀장님 로그 동형 `{id, hits[rank, chunk_id, source_name, snippet(=청크 전문), score=null], answer}` + `latency_ms{search, answer}` + `summary_skipped[]`
- 재시도: 429(쿼터) 시 20·40·60·80·100s 백오프, 5회. 지연은 **성공 호출만** 기록
- 1차 실행: 488 완료, 그중 52건 429 → `--retry-errors`로 재응시(체크포인트에서 오류 건만 복귀)
