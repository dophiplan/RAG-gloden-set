# CI 개선 로드맵 — 무인 오픈까지 (v1.0 · 2026-08-28)

> 근거: r2 전 축 실측 (검색 top5 52.3% · 생성 합격 76.3% · E형 환각 14.6%)
> 원칙: 모든 항목에 조치·담당·예상 효과·검증 방법을 붙인다. 예상치가 빗나가면 버린다.

## 1단계 — 즉시 (설정·규칙 수준, 1~2주)

### ① 리랭크 대상 10 → 30~50 확대 【담당: 플랫폼】 ← 지금 여기
- 근거: 미적중 213건 중 75건(35%)의 정답이 이미 후보 11~50위에 존재 (top50 진단 실측)
- 예상: 검색 top5 +8~17%p → **G3 통과 유력** (52.3 → 60~69%)
- 비용: 리랭크 입력 256자 상한 덕에 지연 증가 제한적
- 검증: 같은 488문항 로그 1벌 → 채점센터 즉시 채점 (앵커·짝지음 비교)

### ② E형 거절 임계값 도입 【담당: 플랫폼】
- 근거: 자료 없는 질문 41개 중 6건에 구체적 답 생성 (예: 근거 없는 배송 기간·갱신 날짜 확답)
- 조치: 검색 근거의 유사도가 임계값 미만이면 "자료에서 확인 불가"로 답하게 강제 + 거절 프롬프트 강화
- 예상: 환각 6건 → 0~2건 → **G1 통과**
- 검증: E형 41 + 정상 문항 표본 재응시 — 환각 감소와 "과잉 거절"(정답 있는데 거절) 부작용을 함께 측정
- 부작용 경계: 임계값이 세면 정상 질문까지 거절함 — 두 지표 동시 병기 필수

### ③ 동봉 span=2 채택 여부 확정 【담당: 플랫폼 판단】
- 실측: 동봉 인정 +2.2%p, 비용은 응답 크기뿐 — 채택해도 무방한 수준

## 2단계 — 중기 (자료·모델 수준, 3~6주)

### ④ 수치·표 직렬화 개선 【담당: 플랫폼(인입 파이프라인)】
- 근거: 회수 실패 122건 중 49건(40%)의 정답이 수치 포함 구역 — 표·요금 나열이 자연문 임베딩에 불리
- 조치: 표를 "행 단위 자연문"으로 풀어 인입 (예: "5분통화무료옵션의 월액은 880엔" 식 문장화)
- 예상: 수치·요금 유형 miss 56% → 30%대 → **G2 접근**
- 검증: 재인입 후 같은 시험지 + 새 chunks export 로 재채점 (재인입 시 export 필수)

### ⑤ 질의 확장(동의어·유의어) 【담당: 플랫폼(검색)】
- 근거: 회수 실패 중 ~35건은 질문-정답 원문의 어휘 겹침 15% 미만 — 사용자 말과 문서 표현의 갭
- 예상: 검색 top5 +3~6%p
- 검증: 구어체 쌍둥이 40쌍 격차(원문항 대비)가 좁아지는지로 확인

### ⑥ 생성 프롬프트 — 수치 인용 규칙 【담당: 플랫폼(생성)】
- 근거: 근거에 있는 수치(253엔)에 근거에 없는 수치(220엔)를 합산해 안내한 실측 사례
- 조치: "금액·기간은 검색 근거에 있는 값만, 출처 청크 명시" 지시 추가
- 검증: 수치 유형 문항의 생성 0점률 변화

## 3단계 — 장기 (다음 분기)

### ⑦ 우회 질문 대응
- 실측: 돌려 묻는 질문 적중 18% — 이번 개선이 전혀 안 통한 유일한 영역
- 후보: 질의 재작성(rewrite) 단계 도입 (우회 질문 → 정면 질문으로 변환 후 검색)
- 검증: r3 시험지에 우회 변형 복원해 측정

### ⑧ 회차 측정 상시화 【담당: 채점센터】
- 앵커 유지 + 개선마다 같은 488문항 재응시 → 위 게이트 대시보드로 상시 추적
- 이미 구축됨 — 로그만 오면 당일 회신

## 순서의 논리

1단계가 끝나면 G1·G3가 잡히고, 2단계에서 G2·G4를 잡는 구조.
**①→② 순서 권장**: 리랭크 확대로 검색이 좋아지면 E형 임계값을 잡기도 쉬워짐 (근거 신뢰도 분포가 갈라져서).

## 하지 말 것 (실측이 말리는 것)

- 리랭크 입력 상한 확대(512): 품질 동일·지연 2.3배 — 실측 완료, 재론 불요
- 임베딩 모델 전면 교체부터 시작: 회수 문제의 40%는 표 직렬화 문제라 모델 탓이 아님 — ④부터
- 시험지 확대(문항 수 늘리기): 측정 정밀도는 이미 충분 — 비용만 증가
