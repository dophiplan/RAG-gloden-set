### 관찰 사항 (반려 트리거는 아니나 보고 — §6)

- **O1 (카드 서술의 한계):** 카드의 "계획" JSON이 `"task": "` 에서 끊긴 건 표시 오류가 아니라 코드가 `plan[:200]`으로 **200자 절단**해 넣기 때문입니다(gen_goldenset.py:292). 즉 카드만으론 배치 구성을 검증할 수 없습니다. 다만 **실제 배분은 LLM 서술이 아니라 코드가 결정론적으로(`remaining[:75]`씩) 수행**하고, 배치 파일은 승인 후 생성됩니다. 따라서 이 게이트가 실제로 통제하는 대상은 "배치 구성"이 아니라 "진행 가부"입니다 — 서술 절단은 무해.
- **O2 (서술 논리 ↔ 코드 동작 불일치, 결과는 우연히 동일):** 카드 서술은 "880÷75=12배치"로 계산하는데, 코드 실제 동작은 "파일럿 30을 먼저 빼고 잔여 850÷75=12차수"입니다. 근거가 다른데 둘 다 12로 떨어져 하자가 가려졌습니다(P-001: 자동 생성 서술도 실측 근거가 아님). 실질 오류는 아니나, LLM 서술을 승인 근거로 읽으면 위험한 구조입니다.
