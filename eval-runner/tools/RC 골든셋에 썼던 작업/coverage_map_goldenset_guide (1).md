# 커버리지맵 · 골든셋 활용 가이드 (청크/문서 export 산출물 기준)

> 입력 데이터 = `scripts/agent/export-chunks.mjs` 산출물 4종(청크/문서 × CSV/JSON).
> 생성 절차는 [chunk_export_procedure.md](./chunk_export_procedure.md) 참조.
> 목적: **RAG 가 실제 아는 것(인입된 청크)** 과 100% 일치하는 평가용 커버리지맵·골든셋 구축.

## 1. 두 파일의 역할 분담

| 파일 | 역할 | 단위 |
|------|------|------|
| `docs-*.csv/json` | **커버리지맵의 뼈대(행)** — 지식 영역 목록 | 문서(URL 변형 접힘) |
| `chunks-*.csv/json` | **골든셋의 근거(정답 앵커)** — 질문 작성 재료 + 채점 키 | 청크(검색 반환 단위) |

조인 키 = `doc_key`(콘텐츠 지문 12hex). 청크 시트의 모든 행에 부여되어 있어 문서 시트와 바로 조인된다.

## 2. docs 파일 → 커버리지맵 본체

docs CSV 를 시트로 열고 열을 덧붙인다:

- **기존 열 활용**: `canonical_url`(영역 식별) · `chunk_count`/`total_chars`(영역 크기 → 질문 수 배분 근거 — 예: 25청크 문서엔 3~5문항, 3청크 문서엔 1문항) · `modality`(`url`=웹 페이지, `document`=링크 PDF) · `url_variants`(같은 내용의 다른 URL — 채점 시 동일 문서로 취급)
- **추가할 열**: `주제 라벨`(요금·하드웨어·약관…) · `목표 질문 수` · `작성된 질문 수` · `상태`

"모든 문서에 최소 1문항"이 채워지면 **문서 수준 커버리지 100%**.

## 3. chunks 파일 → 질문 작성 + 정답 앵커

질문은 문서 요약이 아니라 **청크 원문을 보고** 쓴다 — 검색이 반환하는 단위가 청크라서, 정답 근거가 특정 청크 텍스트에 실재해야 골든셋과 RAG 지식이 일치한다.

1. docs 시트에서 문서 선택 → 그 `doc_key` 로 chunks 파일 필터 → `chunk_index` 순으로 통독.
2. 청크 내용으로 답할 수 있는 질문 작성.
3. 골든셋 행에 **기대 근거 기록**: `doc_key`(문서 수준) + 근거 청크 `point_id`(청크 수준, 복수 가능).

골든셋 행 예시:

| 질문 | 기대 답 요지 | doc_key | point_id(s) |
|------|------------|---------|-------------|
| RemoteMeeting BOX 의 최대 참가자 수는? | …(청크 원문 근거) | ac54af35740c | b4cf0f08-… |

## 4. 평가(채점) 방법

`rag_search` 의 hit(id·`source_url`·payload)을 기대 근거와 대조:

- **느슨한 채점(문서 수준)**: hit 의 `source_url` → docs 시트의 canonical/variants 로 `doc_key` 를 역매핑해 기대 `doc_key` 와 일치하는지. (URL 변형이 있으므로 `source_url` 직접 비교 금지 — 반드시 doc_key 로 접어서 비교.)
- **엄격한 채점(청크 수준)**: hit id == 기대 `point_id`.

**주의(구버전 문서)**: 같은 주제의 신·구 버전이 별도 문서로 공존할 수 있다(예: 현행 약관 vs `terms20170403` 구약관). 골든셋의 정답 출처는 현행 문서 `doc_key` 로 고정하고, 구버전 hit 는 오답(또는 감점)으로 처리한다.

## 5. 역방향 커버리지 점검 (사각지대)

골든셋이 참조한 `point_id` 집합과 chunks 파일 전체를 대조 → **한 번도 근거가 되지 않은 청크** = 질문이 커버하지 못한 사각지대. 문서 수준 100% 이후의 심화 지표(청크 수준 커버리지 %)로 쓴다.

## 6. CSV vs JSON 선택

- **CSV(엑셀)** = 사람 작업(주제 라벨링·질문 작성). UTF-8 BOM 이라 엑셀에서 바로 열림.
- **JSON** = 채점 스크립트 등 자동화(`chunks[]`·`documents[]` 배열).
- 주의: **docs CSV 의 본문은 500자 미리보기**(엑셀 셀 32,767자 제한). 전문이 필요하면 chunks CSV(청크별 전문) 또는 docs JSON(`text`=결합 전문)을 볼 것.
