## 핵심 발견 3건

1. **근거 없는 정답 44건** — 검색은 기대 문서를 놓쳤는데(miss) 답은 맞힌 케이스. 답이 검색 근거가 아니라 모델 자체 지식/타 문서에서 나옴 → 출처 표시가 사실과 다르거나 없을 수 있고, 코퍼스 갱신 시 답이 흔들림. RAG의 신뢰 원칙(근거에서 답이 나온다)에 대한 위험 신호.
2. **컬렉션 경계 미필터** — RC 질문의 검색 결과에 RemoteView 문서·외부 도메인(airepoto.com 등)이 상위 hit로 등장. 의도된 통합 검색인지, 테넌트 필터 누락인지 확인 필요.
3. **E형 환각 30%** — 문서에 없는 기능(예: 존재하지 않는 옵션)을 물으면 10건 중 3건은 지어서 답함. 고객 응대 시 오안내 리스크 직결. 거절(모름) 응답 강화 필요.

## 개선 우선순위 제안

1. 검색 리랭킹·부스팅: PDF 가이드/약관이 블로그류에 밀리는 현상 (SPEC 15%·TERMS 14%)
2. 컬렉션/테넌트 필터 점검 (발견 2)
3. 무근거 생성 억제: 검색 확신도 낮을 때 거절 유도 (발견 1·3 공통 대응)
4. 개선 후 동일 시험지 재응시 → 전후 점수 비교 (시험지·채점기 재사용 가능, 1회성 아님)
