# 팀장님 요청: RC 골든셋 v1.0 실물 RAG 채점 시험 세트 투입

## 1. 배경

RC 골든셋 v1.0 893문항이 생성 → 2축 판정 → 3차 교차검토 → QA 확정을 마쳤습니다.  
이제 실물 RAG 시스템에 투입해 채점하는 단계로 넘어갑니다.

## 2. 요청 사항

첨부 `RC_질문셋.json`의 893개 질문을 RAG 시스템에 1회성 배치로 투입해 주세요.  
결과는 `응답로그_형식스펙.md`에 정의된 JSON 형식으로 1개 파일 export 부탁드립니다.

- 질문셋에는 id와 질문 텍스트만 담겨 있어 정답이나 합격 기준은 포함되어 있지 않습니다.
- 응답 로그의 `id`는 질문셋 id와 1:1로 매칭되어야 합니다.
- 실패·타임아웃 건에도 `id`는 남기고 `hits`/`answer`를 `null`로 처리해 주세요.

## 3. 채점 및 리포트

채점은 우리 쪽에서 수행합니다.

- **검색 채점**: 문서/청크 일치 여부
- **생성 채점**: 필수 요소 포함 여부, 환각 검사

결과로 성적표와 함께 실패 원인을 **검색 / 생성 / 인입 누락**으로 분리한 리포트를 회신드릴 예정입니다.

## 4. 별첨 안내

`문서개선제안.md` — 골든셋 확정 과정에서 발견한 정본 문서 개선 포인트 4건을 취합했습니다.

- 지원 이력 조회 권한 안내 부재
- 파일 저장 경로의 회사 커스텀 상이 가능성 안내 부재
- Ctrl+Alt+Del 전송의 디바이스별 상이 가능성 안내 부재
- 원격접속 페이지 커스터마이징 적용 범위(일부 항목) 안내 부재

문서 담당자께 전달할지 판단해 주시면 감사하겠습니다.

## 5. 참고

응답 로그 `meta`에 코퍼스 버전(크롤 시점)을 기록해 주시면, 채점 성적표에 회차 메타데이터로 남기겠습니다.
