# 문서개선제안 — RC 골든셋 사람 확정(QA) 첨언 취합

- 작성 목적: 골든셋 v1.0 반영 과정에서 QA가 "정본에 안내가 필요하다"고 첨언했으나, 정본(매뉴얼·웹 문서)에 해당 안내 문구가 실재하지 않아 골든셋 정답에 넣을 수 없었던 항목의 취합. 팀장님 전달용.
- 처리 원칙: 아래 항목은 각 문항의 "비고" 컬럼(채점 비반영)에 기재되어 있으며, 정본 문서가 개선되어 해당 문구가 실재하게 되면 그때 발췌 보강으로 정답에 반영한다.

## 1. 지원 이력 조회 권한 안내 부재

- 대상 문항: RC-A033@G-B2-1 (에이전트에서 원격지원 이력을 파일로 뽑을 수 있나요?)
- 근거 문서: 에이전트용 PC지원 사용자 매뉴얼 4.1 (RC-MANUAL-AGPC-068)
- QA 첨언: 지원 이력은 모든 사용자가 뽑을 수 있는 것이 아니므로, 이력 조회 권한을 확인해야 한다는 첨언이 필요하다.
- 확인 결과: 커버리지맵 기준 에이전트 매뉴얼의 지원 이력 단위에는 권한 제약 안내가 없음. (관리자 매뉴얼 통계 메뉴에는 "회사 관리자 권한 계정에서만 확인 가능" 문구가 있으나 — RC-MANUAL-ADMIN-033 — 에이전트 지원 이력과는 별개 메뉴.)
- 개선 제안: 에이전트 매뉴얼 지원 이력 절에 이력 조회/Excel 저장에 필요한 권한 조건을 명시.

## 2. 파일 저장 경로의 회사 커스텀 상이 가능성 안내 부재

- 대상 문항: RC-C008@G-B2-1 (파일 보내기/가져오기 방법)
- 근거 문서: 에이전트용 PC지원 사용자 매뉴얼 4.3.6 (RC-MANUAL-AGPC-101/102)
- QA 첨언: 저장 경로(공유문서\Rsupport\RemoteCall\Received Files)는 회사에서 커스텀한 경우 다를 수 있으므로, 회사 담당자에게 확인해야 한다는 문구가 필요하다.
- 확인 결과: 정본에는 기본 저장 경로만 기재되어 있고 커스텀 시 상이 가능성 안내가 없음.
- 개선 제안: 파일 전송 절에 "회사 설정에 따라 저장 위치가 다를 수 있음" 안내 추가.

## 3. Ctrl+Alt+Del 전송의 디바이스별 상이 가능성 안내 부재

- 대상 문항: RC-A062@G-B2-1 (Ctrl+Alt+Del 전송 가능 여부와 제약) — 유형 A→G 교체 건
- 근거 문서: 에이전트용 PC지원 사용자 매뉴얼 4.3.3 (RC-MANUAL-AGPC-091)
- QA 첨언: 동작이 디바이스에 따라 다를 수 있다는 점을 사용자에게 인지시켜야 한다.
- 확인 결과: 정본에는 Windows 전용·제한/Guest 계정 비활성 조건만 있고 디바이스별 상이 안내는 없음.
- 개선 제안: 해당 기능 절에 디바이스/환경별 동작 차이 가능성 문구 추가.

## 4. 원격접속 페이지 커스터마이징의 적용 범위(일부 항목) 안내 부재

- 대상 문항: RC-F002@G-B6 (원격접속 페이지 기업 브랜드 커스터마이징) — 유형 F→A 교체 건
- 근거 문서: remotecall.com 제품 기능 페이지 (RC-WEB-AGENT-011)
- QA 첨언: 커스터마이징은 일부 항목에 한정된다는 점을 인지시켜야 한다.
- 확인 결과: 정본에는 "로고, 이미지 등을 사용하여 커스터마이징할 수 있습니다"로만 기재되어 있고 커스텀 가능 범위·제한 항목 안내가 없음.
- 개선 제안: 커스터마이징 가능 항목과 불가 항목의 범위를 명시.
