# 응답 로그 형식 스펙

RAG 시스템에 `RC_질문셋.json` 893건을 1회 배치 투입한 후, 아래 JSON 형식으로 1개 파일 export 해 주세요.

## 파일 형식

- 포맷: JSON, UTF-8
- 파일 수: 1개
- 인코딩: UTF-8 (BOM 없음)

## 스키마

```json
{
  "meta": {
    "run_date": "YYYY-MM-DD",
    "system_version": "식별 가능한 버전/커밋/태그",
    "corpus_version": "코퍼스 버전 또는 크롤 시점",
    "top_k": 5
  },
  "responses": [
    {
      "id": "RC-A001@G-B1",
      "hits": [
        {
          "rank": 1,
          "source_url": "검색된 문서 URL",
          "chunk_id": "청크/포인트 ID(있으면)",
          "snippet": "청크 본문 앞 200자(선택)"
        },
        {
          "rank": 2,
          "source_url": "...",
          "chunk_id": "...",
          "snippet": "..."
        }
      ],
      "answer": "시스템이 생성한 최종 답변 텍스트 전문"
    }
  ]
}
```

## 요건

- `id`: 질문셋의 `id`를 그대로 회신. 893건 전량 매칭 키로 사용합니다.
- `hits`: 검색 상위 5개(`top_k=5`). 순위(`rank`) 1~5를 포함해 주세요.
  - `source_url`: 검색된 문서 URL
  - `chunk_id`: 청크 또는 검색 포인트 ID(시스템에 없으면 null)
  - `snippet`: 청크 본문 앞 200자(선택, 없으면 null)
- `answer`: 후처리 없는 최종 생성 답변 전문.
- 893건 전량 포함.
  - 실패/타임아웃/에러 건에도 `id`는 남기고, `hits`와 `answer`를 `null`로 채워 주세요.
- `meta.corpus_version`: 코퍼스 버전이나 크롤 시점을 기록해 주시면, 채점 성적표에 회차 메타데이터로 남깁니다.
