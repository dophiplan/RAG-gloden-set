# 🎯 골든셋 만들기 — 전체 프로세스 가이드

> 이 문서 하나만 보고 따라 하면 된다. (기준: 생성규칙서 v3.4 · SOP v1.4 · 런북 v3.3 · 작업지시서 v0.4) RC를 예시로 쓴다. 다른 제품은 `RC`를 `RV`/`RM`/`HR`로만 바꾸면 똑같다.
> 회색 박스(``` ```)는 통째로 복사해서 쓰는 것. **터미널 명령은 터미널에, 한국어 지시는 AI 채팅에.** 섞지 않는다.

---

## 등장인물

- **나** = 너 (판단·저장·승인하는 사람)
- **AI-1** = 만드는 AI (커버리지맵·골든셋 생성) — Claude 새 채팅 하나
- **AI-2** = 채점하는 AI (2축) — ⚠️ **AI-1과 다른 새 창**
- **AI-3** = 분류하는 AI (3차) — 또 다른 새 창 (의심·반려 많을 때만)
- **Claude(설계본부)** = 검수해주는 채팅 (지금 이 대화)
- **터미널** = 맥북 검은 창

## 🔧 준비 (딱 한 번만)

**1.** [나] zip을 풀어 `goldenset-system` 폴더를 홈에 둔다 → `~/goldenset-system`

**2.** [나] 원문(자료)을 `goldenset-system/products/RC/원문/` 폴더에 전부 복사한다

**3.** [터미널] 터미널을 연다 (⌘+스페이스 → "터미널"). 아래를 붙여넣고 엔터:
```
pip3 install PyMuPDF openpyxl
```

## 1부 — 커버리지맵 만들기

**4.** [나] 브라우저에서 Claude 새 채팅을 연다 = **AI-1**

**5.** [나→AI-1] 파일 2개를 첨부한다: ① 원문(자료) ② `goldenset-system/kit/커버리지맵_작업지시서.md`

**6.** [나→AI-1] 배치 계획부터 받는다. 이렇게 말한다:
```
첨부한 원문(자료)을 먼저 훑고, 분해를 시작하기 전에 배치 계획부터 보고해:
- 원문 규모상 몇 배치로 나눠야 하는지 (한 번에 되면 1배치)
- 각 배치에 뭐가 들어가는지 (예: Batch1=사양서, Batch2=매뉴얼, Batch3=헬프데스크)
- 배치별 예상 단위 수
내가 승인하면 그때 Batch1부터 시작해.
```

**6-1.** ✋[나] AI-1의 배치 계획을 확인한다 — **빠진 원문이 없는지** 본다 (계획에 사양서·매뉴얼·헬프데스크가 다 있나?). 빠졌으면 "이것도 넣어" 하고 다시 계획받는다

**6-2.** [나→AI-1] 승인 후 이렇게 말한다:
```
승인. Batch1부터 시작해. 작업지시서 v0.4 기준(21컬럼)으로:
- 헤딩/절제목만 있는 단위는 상태=근거약함, 본문 미확보는 상태=사람확인으로 처음부터 표기
- TC는 보류(표본설계 대기), 사유를 비고에
- 배치 하나 끝날 때마다 xlsx로 내고, 단위 수를 숫자로 보고해
```

**7.** [나] **배치가 나올 때마다** 받은 파일을 `goldenset-system/products/RC/`에 저장하고, **Claude(설계본부)에 올려 검수받는다** — "이 배치가 계획대로 나왔나 + 뭐가 남았나" 확인.
> ⚠️ 한 배치 통과했다고 끝난 게 아니다. 계획표의 배치가 **다 모일 때까지** 6-2~7을 반복한다. (RC에서 "955행 완성"이라던 게 실은 사양서 배치 하나였던 사고 방지)

**8.** [나→AI-1] 모든 배치가 검수 통과하면:
```
배치들을 하나로 합쳐 통합정본 xlsx로 줘. 총 단위 수와 배치별 구성 숫자를 보고해.
```
→ 받은 통합본을 `goldenset-system/products/RC/coverage_map.xlsx`로 저장하고 Claude에 최종 검수. 합격하면 9번으로

**9.** ✋[나] 설계를 정해 AI-1에게 말한다 (예: "사양서·KI 전수, 매뉴얼 대표 커버, 헬프데스크 이번 제외")

## 2부 — 골든셋 문항 만들기

**10.** [나→AI-1] 파일 3개를 첨부한다: ① `goldenset-system/kit/생성규칙서.md` ② `goldenset-system/kit/SOP.md` ③ 방금 그 coverage_map.xlsx

**11.** [나→AI-1] 이렇게 말한다:
```
첨부한 생성규칙서 v3.4와 SOP v1.4대로, 커버리지맵의 미검토 단위에서 골든셋 문항을 만들어줘.
문항 수가 많으면 배치 계획(몇 배치·각 범위·예상 문항수)부터 보고하고, 내 승인 후 시작해.

v3.4 규칙 반드시 준수:
- answer_type 컬럼 필수 (single / multi_equivalent)
- 질문 유일성 — 질문만 읽고 어느 단위인지 특정되게 (§3.7)
- E형은 정본 원문에 아예 없는 것만, E형 발췌 칸은 공란 (§3.2)
- 원천 빈 값은 정답에 넣지 않기 (§3.7)
- 정답은 필수 요소만, 150자 이내 (§3.7)
- acl_level은 전부 all
완료 보고에 항목별 건수를 숫자로 명시해. 결과는 xlsx로.
```

**12.** [나] 받은 파일을 `goldenset-system/products/RC/goldenset_draft.xlsx`로 저장한다

**13.** [나] 그 파일을 **Claude(설계본부)에 올려 검수**받는다 → 불합격이면 Claude가 주는 수정 지시를 AI-1에게 전달하고 12번부터 반복
> ⚠️ AI가 "다 고쳤다"고 해도 믿지 말고 매번 Claude에 올려 확인. **변경 건수 숫자 보고가 없으면 반려.**

## 3부 — 1축 검증 (터미널)

**14.** [터미널] 폴더로 이동한다: `cd ` (cd 치고 한 칸 띄우기) → Finder에서 `goldenset-system` 폴더를 터미널 창에 **드래그** → 엔터

**15.** [터미널] 붙여넣고 엔터:
```
python3 tools/run_1axis.py -p RC -g products/RC/goldenset_draft.xlsx -c products/RC/원문/
```
→ `products/RC/verify_1axis.json`이 자동으로 생긴다

**16.** [터미널] 붙여넣고 엔터:
```
python3 tools/postprocess_1axis.py -p RC -v products/RC/verify_1axis.json -c products/RC/coverage_map.xlsx
```
→ `products/RC/human_review_1axis.csv`가 생긴다

**17.** ✋[나] 그 CSV를 엑셀로 열어 **거기 뜬 것만** 처리한다:
- missing(원문에 없음) → 원문 찾아 발췌 고치거나 문항 버림
- partial(살짝 다름) → 원문대로 발췌 다듬음
- 고칠 게 많으면 AI-1에게 시킨다

## 4부 — 2축 검증 (다른 AI)

**18.** [터미널] 붙여넣고 엔터:
```
python3 tools/make_batches.py -p RC -g products/RC/goldenset_draft.xlsx
```
→ `products/RC/handoff/` 안에 batch01, batch02… 가 생긴다

**18-1.** ✋[관문 — 이 제품에서 2축이 처음일 때만 1회] **채점기(judge) 신뢰도 검사**부터 한다:
- Claude(설계본부)에 말한다: `judge 캘리브레이션 세트 만들어줘` → 정상 문항 15 + 일부러 망가뜨린 문항 15 = 30건을 만들어준다
- 그 30건을 AI-2(아래 19번의 새 창)에 채점시킨다
- 결과를 Claude에 올린다 → **일치율 ≥90%면 통과**, 미만이면 Claude가 judge 프롬프트를 고쳐주고 재검사
> 채점기가 못 미더우면 채점 결과 전체가 흔들린다 — 그래서 시험 전에 채점기부터 검사한다. (이미 통과한 제품이면 이 단계 건너뜀)

**19.** [나] 브라우저에서 **완전히 새 창**을 연다 = **AI-2** (⚠️ AI-1 창 아님! 여기서 자기검증 금지가 깨진다)

**20.** [나→AI-2] `goldenset-system/kit/judge_prompt_2axis_표준.md`를 첨부하고 말한다:
```
이 기준으로 채점해줘.
```

**21.** [나→AI-2] `products/RC/handoff/batch01_….txt`를 열어 내용을 복사 → AI-2에 붙여넣기 → 결과(JSON)를 받는다

**22.** [나] batch02, 03… 끝까지 반복한다(같은 AI-2 창). 받은 결과들을 `products/RC/handoff/`에 저장한다

**23.** [터미널] 붙여넣고 엔터:
```
python3 tools/collect_2axis.py -p RC
```
→ 타당/의심/반려 개수가 나온다

## 5부 — 확정과 마감

**24.** [나] 의심·반려가 **많으면**: 새 창(**AI-3**)을 열고 `goldenset-system/kit/3차_교차검토_프롬프트.md` + 2축 결과를 주며 말한다:
```
사람이 볼 것만 추려줘.
```
의심·반려가 **몇 개 안 되면** 이 단계는 건너뛴다

**25.** ✋[나] 의심·반려만 보고 판정한다 — 진짜 틀렸으면 AI-1에게 "이 문항 이렇게 고쳐"(고친 건 15번부터 다시), 채점이 깐깐했을 뿐이면 통과

**26.** [나] 다 통과하면 검증 상태를 `검증완료`로 바꾸고 `goldenset-system/products/RC/goldenset_final.xlsx`로 저장한다

**27.** [나→AI-1] 이렇게 말한다:
```
골든셋 결과(커버됨/미커버+사유/사람확인)를 커버리지맵에 조인해서 미검토 0으로 만들어줘.
```
→ 받아서 `goldenset-system/products/RC/coverage_map_final.xlsx`로 저장한다

**28.** [나] final 파일 2개를 다른 곳에 백업한다. 못 한 것(보류)은 사유+재개조건을 적어둔다. **끝** 🎉

## ⚠️ 절대 규칙 (외우기)

1. **19번은 반드시 새 창** — AI-1 창에서 채점하면 전부 무효 (자기검증 금지)
2. **발췌는 원문 그대로** — 요약·수정 금지 / E형만 발췌 공란
3. **missing은 절대 자동완료 안 함** — 사람이 원문 확인
4. **골든셋 acl_level = 전부 all** — 커버리지맵 값은 acl_참고로 보존
5. **질문은 유일하게** — 질문만 읽고 어느 단위인지 특정되게
6. **AI 완료 보고는 건수 숫자로** — 숫자 없는 "완료"는 반려. 항상 Claude에 올려 검수
7. **수정본 검수는 등식으로** — 총 행수 = 기존 + 신규 − 삭제 (1이라도 어긋나면 무단 추가/삭제 → 반려)

## 🚦 배치 관문 (커버리지맵·골든셋 공통) — 왜 중요한가

원문이 크면 AI-1이 배치로 나눠 일한다. 이때 관문 3개를 꼭 지킨다:
1. **시작 전** — 배치 계획 승인 (몇 배치로 뭘 할지 먼저 안다)
2. **배치마다** — 검수 (반쪽을 전체인 척 못 하게)
3. **끝에** — 통합본 검수 (합칠 때 빠진 배치 없나)

→ 이걸 안 하면 "어? 갑자기 배치?" "이게 전부인가?" 하는 혼란이 생긴다.

## 🆘 막히면

- **"몇 번에서 막혔어"** 라고만 Claude에 말하면 바로 짚어준다 (번호로 소통)
- 터미널 "No such file" 에러 → 폴더 위치 틀림. `cd ~/goldenset-system` 다시 하고 `ls`로 kit·tools·products 보이나 확인
- 원문이 다 missing으로 나옴 → PyMuPDF 설치 안 함. 준비 3번 다시
- 지금 어디까지 했는지 모름 → `ls products/RC/` 쳐서 어떤 파일 있나 본다
- AI한테 뭐라고 할지 모름 → 이 문서의 회색 박스를 통째로 복사해서 붙여넣기
