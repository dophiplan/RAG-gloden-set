## 1. 원칙 (자기완결 원문 — v1 파일 없이도 유효)

- **P-02 선언≠실측**: 모든 카운트·상태는 파이썬 실측 후에만 인정. "완료" 선언만 있으면 반려. 숫자 없는 보고 반려.
- **P-04 역검색 문맥 확인**: 공백 제거 정규화는 우연 조합을 만든다 — 판례: "분할납부↔따져봐야 **할 부**분", "인수↔온라**인 수**업", "구장↔연**구 장**비", URL 경로 'education'. 히트=자동 기각 아님, 문맥 열람 의무.
- **P-05 E형 보수 기각**: 유사 기능·제도·조항이 코퍼스에 실재하면 E("자료에 없음") 기각. '전제 상충' 기각 범주 포함.
- **P-06 흡수 + 확장**: 흡수 대표는 직접 커버 단위여야 하며, 전 배치 범위 합집합으로 성립(교차 배치 흡수 인정). 연쇄 흡수는 평탄화.
- **★ 합집합 원칙**: 직접 커버 대조는 생성·검수 양측 모두 배치 산출물 전체(파일럿+전 차수) 합집합 범위로. 설계본부가 마감 파일만 검색해 오반려낸 사고 2회 — 반려 전 반드시 전 파일 합집합 확인. assert의 대조 기준 자체도 검증 대상.
- **검수 오탐 시 공개 정정**: 검수자도 틀린다. 틀리면 즉시 인정하고 판례로 남긴다.
- 파일 버전 단조 증가(vN_M), 낱장 문서 발행 금지(표준의 집은 패키지 하나), 로컬 폴더 data/tools/results 분리.
- **DEC-028**: 작업 AI 착수는 명시적 착수 지시문으로만. **DEC-029**: 맥락 절단 부적격 판정 전 섹션 앵커·인접 단위 대조 의무.

## 5. 검수 표준 절차 (자기완결 원문)

**모든 배치/산출물 제출 시 실측 항목 9**: ① 행수·유형 분포 = 보고와 일치 ② 1축(발췌↔맵 사실 필드) 전 세그먼트 재대조 ③ citation 실재 ④ 질문 중복 0 ⑤ 커버 등식(직접+흡수+부적격+잔여=풀, 소실 0) ⑥ 흡수 대표의 직접 합집합 실재 ⑦ E형은 검수측 독립 역검색 재수행(기초어 단독 포함) ⑧ 앵커(T-1 등) 전건 ⑨ 부적격 사유 전건.

**1축 대조 표준 코드 패턴**:
```python
import openpyxl, unicodedata, re
def N(s): return unicodedata.normalize('NFC', str(s).strip()) if s is not None and str(s).strip() else ""
def norm(s): return re.sub(r'\s+','', N(s)).lower()
# 맵: '…커버리지맵' 시트들에서 {Unit ID: 사실}
# 발췌 세그: re.split(r'\|\|', 발췌) 후 선두 [라벨]·따옴표 제거, len<6 스킵
# 판정: norm(seg) in norm(인용 단위들의 사실 연결) — 불일치 0이어야 합격
# 인용 추출·앵커 패턴은 제품 terrain 프로파일에서 로드 (RV: RV[A-Z]*-…-\d+ / 앵커 어미 게시|시행|인덱싱|작성|서술)
```
주의: 한글 파일명 NFD 문제 — os.listdir + NFC 정규화로 특정, 셸 글롭 금지. openpyxl read_only=True, data_only=True.

**회신문 형식**: `[설계본부 검수 — <판정>]` + 실측 수치 + 판례 인용 + 다음 단계 명시적 착수 지시. 반려 시 수정 지시 번호 매김.
