## 1. 이 프로젝트가 뭔지 (한 문단)

알피스는 **회사 전체 지식(문서+DB)을 하나의 RAG 엔진**으로 묻고 답하게 하는 사내 프로젝트다. 이 골든셋은 그 엔진이 **"몇 점짜리인지" 수치로 재는 시험지 100문항**이다. 제품별(RC/RV/RM/HR) 전수 골든셋과는 **별개 · 상위**의, 엔진 전체 베이스라인 측정용이다.

⚠️ **사내 제품별 골든셋 표준(goldenset-system, 생성규칙서 v3.3 등)과 이 키트는 규격이 다르다. 두 세트를 한 세션에서 섞지 마라.** (컬럼 수·유형·조인 방식이 달라 혼동 시 오염된다.) 알피스는 **이 폴더의 키트만** 쓴다.

## 2. 새 AI(AI-1)에게 첫 메시지 — 이대로 복사

```
[알피스 골든셋 작성 시작]

첨부 문서:
① 골든셋_작성키트_v0.3_보완패치.md  ← 규칙(최우선)
② RAG_골든데이터셋_작성키트_v0.2.docx  ← 방법론 본체
③ 알피스_프로젝트차터_v0.1.docx  ← 배경

지시:
1. ②의 스키마·유형·루브릭을 따르되, ①의 5개 보완(answer_type 컬럼·G유형 추가·E형 근거·질문 유일성/빈값·사내자산 재사용)을 반드시 반영해.
2. 이번 배치 범위: 유형 ___ , ___문항, 대상 ___ 카테고리. (한 번에 100문항 금지 — 유형 1~2개씩)
3. 정답·근거는 반드시 실제 자료에서. 자료 밖은 지어내지 말고 [자료 없음] 표기.
4. 완료 보고: 유형별 문항 수 · 충돌 건수 · 내가 판정할 항목을 숫자로.
5. 출력: 엑셀 1개 (시트1 골든셋 12컬럼 / 시트2 충돌목록 / 시트3 커버리지 대조표).

먼저 이 배치의 작성 계획(유형별 몇 문항, 어떤 근거 자료 쓸지)부터 보고하고, 내 승인 후 시작해.
```

> 밑줄(`___`)은 그 배치에서 정해 채운다. 예: "유형 A, 15문항, RemoteView 카테고리".

## 3. 작업 순서 (100문항까지)

1. **[나]** 능력 목록 20~30개 작성 (키트 2장) — "무엇을 테스트할지"
2. **[나+팀]** 유형 배정·비중 확정 (A~G 7유형)
3. **[AI-1]** 유형별 배치로 문항 생성 (한 번에 1~2유형) — 배치마다 계획 보고 → 승인 → 생성
4. **[나]** 각 배치 검수 (근거가 실제 자료에 있나 / 12컬럼·유형 규칙 지켰나)
5. **[다른 AI = AI-2]** 정답 타당성 교차검증 (자기검증 금지 — AI-1과 다른 세션)
6. **[나]** 충돌·의심 판정 → 검증완료 승격
7. 100문항 완성 → 베이스라인 측정(엔진에 투입)으로 넘어감

> 배치·검수·교차검증 원칙은 사내 4제품에서 검증된 방식과 동일하다. AI가 "다 됐다"고 하면 믿지 말고 **건수 숫자 보고 + 파일 검수**로 확인한다.

## 4. 절대 규칙 (알피스판)

1. **정답·근거는 실제 자료에서만** — 자료 밖은 [자료 없음], 지어내면 유형 E 사고
2. **교차검증은 다른 AI 세션** (자기검증 금지)
3. **충돌(하나만 맞음)은 정답 여러 개로 넣지 말고 충돌 시트로** — 심판은 사람
4. **한 번에 100문항 금지** — 자료 준비된 유형 1~2개씩 배치
5. **게이트 위반(E 환각·F 권한노출)은 평균에 묻지 말고 건수로 최상단 표기**
6. **사내 커버리지맵 자산 우선 사용** (보완패치 5번) — 근거 중복 탐색 방지
