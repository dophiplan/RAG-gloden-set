# e-BNF: 디자인이 곧 코드가 되는 디자인 툴

> "디자인을 만지면 곧 코드가 된다"

## 개요

기획·디자인·개발이 같은 단일 원본(JSON 트리)을 보고, 그게 화면·코드·이력 세 얼굴로 비치는 디자인 툴입니다.

## 개발 단계

### ✅ M0: 화면에 상자 그리면 JSON 된다
- **M0-1**: JSON 트리 자료구조 + 조작 함수
- **M0-2**: 트리를 화면에 그리기 (DOM/Flexbox)
- **M0-3**: 프레임 만들고 채우기 → 트리 수정
- **M0-3b**: 크기/비율 (레고식 자유)
- **M0-4**: 트리를 JSON 텍스트로 실시간 표시

### ✅ M1: 트리 → HTML/CSS 출력
- **M1-1**: 순수 변환 함수 (DOM 없이 깨끗한 HTML/CSS)

### 🚧 M2: 변경하면 이력이 남는다 (해자)
- **M2-1**: Diff 엔진 (전/후 트리 → 변경 목록)
- **M2-2**: 자연어 뷰 (변경 목록 → 사람 말)
- **M2-3**: 커밋·되돌리기
- **M2-4**: before/after 화면

## 파일 구조

```
.
├── tree.ts           # M0-1: 핵심 자료구조
├── tree.test.ts      # M0-1 테스트
├── adapter.ts        # M0-2: 화면 렌더링
├── editor.ts         # M0-3: 편집 도구
├── export.ts         # M1-1: HTML/CSS 출력
├── export.test.ts    # M1-1 테스트
├── diff.ts           # M2-1: Diff 엔진 (예정)
├── demo.html         # M0-2 데모
├── demo-editor.html  # M0-3 데모
├── demo-m0.html      # M0-4 최종 데모
└── 지시서/           # 작업 지시서
```

## 실행 방법

```bash
# 개발 서버 실행
python3 -m http.server 8080

# 브라우저에서 열기
open http://localhost:8080/demo-m0.html
```

## 핵심 원칙

1. **절대 좌표 금지** - 위치는 flex 규칙으로만 계산
2. **트리가 진실** - 화면은 트리의 그림자일 뿐
3. **크기는 4가지** - 고정/꽉채움/비율/내용맞춤
