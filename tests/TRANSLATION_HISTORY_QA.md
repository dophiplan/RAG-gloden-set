# 🧪 개별 번역 히스토리 기능 QA 테스트 시나리오

> **버전**: 1.0  
> **작성일**: 2026-03-03  
> **테스트 대상**: 개별 번역 항목 "버전 기록" 기능

---

## 📋 개요

개별 번역 항목에서 "버전 기록" 버튼을 클릭하여 변경 이력을 보고 롤백하는 기능의 테스트 시나리오입니다.

---

## 1️⃣ UI/UX 테스트

### 시나리오 1: 버튼 표시 ✅

| 항목 | 내용 |
|------|------|
| **사전 조건** | 번역 관리 페이지 접속, 번역 항목 1개 이상 존재 |
| **테스트 단계** | 1. 번역 테이블 확인<br>2. 각 행의 "버전 기록" 버튼 위치 확인 |
| **기대 결과** | - 버튼이 명확하게 보임<br>- 아이콘(Clock/History) 또는 "히스토리" 텍스트 표시<br>- 호버 시 툴팁 "버전 기록" 표시 |

#### 체크리스트
- [ ] 번역 테이블의 각 행에 버전 기록 버튼이 표시됨
- [ ] 버튼 아이콘이 시계 또는 히스토리 아이콘으로 표시됨
- [ ] 버튼에 마우스 호버 시 "버전 기록" 툴팁 표시
- [ ] 버튼이 액션 버튼 그룹(삭제, 용어집 추가 등) 내에 위치함

---

### 시나리오 2: 모달 열기/닫기 ✅

| 항목 | 내용 |
|------|------|
| **테스트 단계** | 1. 특정 번역 행의 "버전 기록" 버튼 클릭<br>2. 모달 닫기 버튼(X) 클릭<br>3. ESC 키로 닫기 테스트 |
| **기대 결과** | - 모달이 부드럽게 열림<br>- 변경 이력 목록이 표시됨<br>- 닫기 버튼/ESC로 정상 닫힘 |

#### 체크리스트
- [ ] 버튼 클릭 시 모달이 열림 (애니메이션 포함)
- [ ] 모달 헤더에 "버전 기록" 제목 표시
- [ ] 모달에 닫기 버튼(X) 표시됨
- [ ] 닫기 버튼 클릭 시 모달이 닫힘
- [ ] ESC 키 입력 시 모달이 닫힘
- [ ] 모달 외부 클릭 시 모달이 닫힘 (선택적)

## 2️⃣ 기능 테스트

### 시나리오 3: 변경 이력 조회 ✅

| 항목 | 내용 |
|------|------|
| **사전 조건** | 특정 번역에 변경 이력이 존재 |
| **테스트 단계** | 1. "버전 기록" 버튼 클릭<br>2. 변경 이력 목록 확인 |
| **기대 결과** | - 변경 날짜/시간 표시<br>- 변경자 이름 표시<br>- 변경 전/후 값 표시<br>- 현재 버전 표시 |

#### 체크리스트
- [ ] 변경 이력 목록이 시간순(최신순)으로 정렬됨
- [ ] 각 항목에 변경 날짜/시간 표시
- [ ] 각 항목에 변경자 이름 표시
- [ ] 변경 전 값이 취소선으로 표시됨 (확장 시)
- [ ] 변경 후 값이 표시됨
- [ ] 현재 버전에는 "현재" 배지가 표시됨
- [ ] 변경 유형에 따라 다른 색상 배지 표시 (audit: 복색, translation: 녹색)

#### 테스트 데이터 예시
```json
[
  {
    "type": "audit",
    "changeDescription": "상태: 요청 → 검수",
    "changedBy": "홍길동",
    "createdAt": "2024-01-15T10:00:00Z"
  },
  {
    "type": "translation",
    "changeDescription": "KO 번역 수정",
    "previousValue": "안녕하세요",
    "newValue": "Hello World",
    "changedBy": "김철수",
    "createdAt": "2024-01-14T09:30:00Z"
  }
]
```

### 시나리오 4: 롤백 기능 ✅

| 항목 | 내용 |
|------|------|
| **사전 조건** | 변경 이력 2개 이상 존재 |
| **테스트 단계** | 1. "버전 기록" 버튼 클릭<br>2. 이전 버전 선택<br>3. "복구" 버튼 클릭<br>4. 확인 대화상자 확인 |
| **기대 결과** | - "복구되었습니다" 메시지<br>- 번역 텍스트가 이전 버전으로 변경됨<br>- 새로운 변경 이력 추가됨 |

#### 체크리스트
- [ ] 이전 버전 항목에 "복구" 버튼이 표시됨
- [ ] 현재 버전에는 "복구" 버튼이 표시되지 않음
- [ ] "복구" 버튼 클릭 시 확인 대화상자 표시
- [ ] 확인 시 "복구가 완료되었습니다" 메시지 표시
- [ ] 번역 텍스트가 선택한 버전으로 변경됨
- [ ] 새로운 변경 이력이 추가됨 (롤백 기록)
- [ ] 모달이 닫히거나 변경 이력이 새로고침됨

## 3️⃣ 에러 케이스

### 시나리오 5: 변경 이력 없음 ✅

| 항목 | 내용 |
|------|------|
| **사전 조건** | 신규 생성된 번역 (변경 이력 없음) |
| **테스트 단계** | 1. "버전 기록" 버튼 클릭 |
| **기대 결과** | - "변경 이력이 없습니다" 메시지<br>- 빈 목록 또는 안내 메시지 |

#### 체크리스트
- [ ] 변경 이력이 없으면 안내 메시지 표시
- [ ] 메시지: "변경 이력이 없습니다."
- [ ] UI가 깨지지 않고 정상적으로 표시됨

---

### 시나리오 6: API 에러 ✅

| 항목 | 내용 |
|------|------|
| **사전 조건** | 네트워크 오프라인 또는 서버 에러 |
| **테스트 단계** | 1. "버전 기록" 버튼 클릭 |
| **기대 결과** | - 에러 메시지 표시<br>- "변경 이력을 불러오는데 실패했습니다" |

#### 체크리스트
- [ ] 네트워크 오류 시 에러 메시지 표시
- [ ] 서버 500 에러 시 에러 메시지 표시
- [ ] 인증 만료 시 로그인 유도 또는 401 메시지
- [ ] 에러 발생 시 로딩 상태가 해제됨
- [ ] 재시도 버튼 또는 방법 제공 (선택적)

#### 에러 케이스 상세
| 상황 | 기대 결과 |
|------|----------|
| 401 Unauthorized | "인증이 필요합니다." 메시지 |
| 404 Not Found | "해당 버전을 찾을 수 없습니다." 메시지 |
| 500 Server Error | "변경 이력을 불러오는데 실패했습니다." 메시지 |
| Network Error | "네트워크 연결을 확인해주세요." 메시지 |

| **테스트 단계** | 1. 여러 항목 선택<br>2. "버전 기록 보기" 버튼 클릭<br>3. 사이드바에서 히스토리 확인 |

## 🔧 테스트 환경 설정

### 필요한 조건
```bash
# 1. 개발 서버 실행
cd ~/translation-manager
npm run dev

# 2. 테스트 계정 로그인
# http://localhost:3000/login

# 3. 테스트 데이터 준비
# - 번역 항목 2개 이상 생성
# - 하나는 변경 이력이 있는 항목
# - 하나는 신규 생성된 항목 (변경 이력 없음)
```

### 테스트 데이터 시나리오
1. **변경 이력 있는 번역**:
   - 한국어 번역을 2-3회 수정
   - 상태를 한 번 변경
   
2. **신규 번역**:
   - 방금 생성된 번역 (변경 이력 없음)

## 📈 성능 기준

| 항목 | 기준 | 측정 방법 |
|------|------|----------|
| 모달 열기 | < 500ms | 버튼 클릭 ~ 데이터 표시 |
| 변경 이력 로딩 | < 2초 | API 호출 ~ 렌더링 완료 |
| 롤백 완료 | < 3초 | 복구 클릭 ~ 성공 메시지 |
| 메모리 사용 | < 50MB | Chrome DevTools |
