# 용어집 자동 학습 기능 변경사항

## 📅 날짜: 2026-02-05

## 🎯 목적
번역 과정에서 자동으로 전문 용어를 감지하고, AI 학습을 통해 일관성 있는 번역을 제공하는 시스템 구축

---

## 📦 새로 추가된 파일

### 1. 용어 감지 시스템
**파일**: `/src/lib/glossary/term-detector.ts`
- 용어 자동 감지 로직
- Corrections 및 Translations 분석
- 통계 기반 신뢰도 계산
- 기존 용어집 중복 제거

**주요 함수**:
```typescript
- detectTermsFromCorrections(): Corrections에서 반복 패턴 분석
- detectTermsFromTranslations(): 번역 결과에서 용어 추출
- suggestGlossaryTerms(): 최종 제안 생성
- extractShortTranslations(): 짧은 번역 구문 추출
- extractKoreanTerms(): 한국어 용어 추출
```

### 2. API 엔드포인트

#### `/src/app/api/glossary/suggest/route.ts`
- **GET**: 제안된 용어 목록 조회
- 쿼리 파라미터: `language`, `product_code`, `limit`
- 응답: `{ suggestions: TermSuggestion[] }`

#### `/src/app/api/glossary/suggest/approve/route.ts`
- **POST**: 제안 승인 및 용어집 추가
- 다중 용어 일괄 처리
- 제품 연결 자동 처리
- 에러 핸들링 포함

#### `/src/app/api/glossary/generate-context/route.ts`
- **POST**: OpenAI를 이용한 용어 설명 자동 생성
- GPT-4o 모델 사용
- 한국어 설명 생성
- 샘플 문맥 분석

### 3. UI 컴포넌트

#### `/src/app/(dashboard)/glossary/suggestions/page.tsx`
**완전히 새로운 제안 관리 페이지**

**기능**:
- 제안 목록 표시 (용어, 번역, 언어, 빈도, 신뢰도)
- 3단계 필터링 (언어, 제품, 신뢰도)
- 다중 선택 및 일괄 승인/거부
- AI 자동 설명 생성
- 제품 다중 선택
- 사용 예시 표시 (최대 5개)
- 실시간 로딩 상태 표시
- DashboardLayout 적용

**UI 특징**:
- 신뢰도별 색상 코드 (녹색/노란색/빨간색)
- 반응형 그리드 레이아웃
- 토글 가능한 사용 예시
- 인라인 설명 편집

## 🔧 주요 개선사항 (QA 후 디버깅)

### 1. term-detector.ts 전면 개선
**이전 문제**:
- 전체 문장을 용어로 취급
- 한국어-번역 매칭 부정확
- 신뢰도 계산 없음

**개선 내용**:
- 짧은 단어/구문만 추출 (1-3단어)
- 한국어 용어 추출 함수 분리 (`extractKoreanTerms`)
- 통계 기반 신뢰도 계산 (최소 50%)
- 빈도와 다양성 기반 필터링

**알고리즘**:
1. 번역에서 짧은 단어/구문 추출
2. 한국어 원문에서 용어 추출
3. 공동 출현 빈도 계산
4. 가장 많이 함께 나타난 한국어-번역 쌍 선택
5. 신뢰도 = 최대 빈도 / 전체 빈도

### 2. UI/UX 개선
**추가된 기능**:
- DashboardLayout 적용 (일관된 네비게이션)
- "돌아가기" 버튼
- 신뢰도 시각화 (색상 배지)
- AI 생성 중 상태 표시 (`generating`)
- 반응형 디자인 (md: breakpoint)

### 3. 에러 핸들링 강화
**추가된 처리**:
- API 호출 실패 시 사용자 친화적 메시지
- OpenAI API 키 없을 때 안내
- 빈 결과 처리
- try-catch 블록 추가
- console.error로 디버깅 정보

## 📚 사용자 가이드

### 1. 용어 감지 시작하기
1. 번역 작업을 정상적으로 진행
2. 동일한 용어가 3번 이상 반복 사용되면 자동 감지
3. 용어집 페이지에서 "제안된 용어" 배지 확인

### 2. 제안 검토하기
1. "제안된 용어" 탭 클릭
2. 필터로 원하는 언어/제품 선택
3. 각 제안의 신뢰도와 사용 예시 확인
4. 필요 시 AI로 설명 생성 또는 직접 작성

### 3. 용어 승인하기
1. 승인할 용어 체크박스 선택
2. 적용할 제품 선택 (선택사항)
3. "선택 항목 승인" 버튼 클릭
4. 승인된 용어가 용어집에 추가됨

### 4. AI 번역에서 확인하기
1. 새로운 번역 요청
2. 승인된 용어가 자동으로 일관되게 번역됨
3. 설명이 있는 용어는 더 정확한 문맥 고려

## 🐛 알려진 이슈

### 1. 용어 추출 정확도
- **이슈**: 복잡한 문장에서 용어 추출 제한적
- **임시 해결**: 짧은 번역(50자 이하)만 처리
- **향후 개선**: NLP 라이브러리 도입

### 2. 언어별 최적화 부족
- **이슈**: 모든 언어에 동일한 로직 적용
- **영향**: CJK 언어에서 단어 경계 감지 어려움
- **향후 개선**: 언어별 토크나이저

### 3. 제품 필터링 제한
- **이슈**: translation_products가 없는 번역 제외됨
- **임시 해결**: 필터 없이 전체 조회 권장
- **향후 개선**: NULL 처리 개선
